🚀 COMANDOS PARA COPIAR Y PEGAR
================================

IMPORTANTE: Reemplaza TU_USERNAME con tu usuario GitHub ANTES de copiar

Ejemplo: si tu usuario es "luisa2010", cambias TU_USERNAME por "luisa2010"

================================================================

PASO 1: En Terminal, pega esto:

```bash
git remote add origin https://github.com/TU_USERNAME/catalina-15.git
git branch -M main
git push -u origin main
```

Reemplaza TU_USERNAME con tu usuario GitHub.

================================================================

¿Qué hace esto?

• git remote add origin...  = Conecta con GitHub
• git branch -M main        = Nombra la rama principal
• git push -u origin main   = Sube todo a GitHub

Cuando termine:
✅ Todo está en GitHub
✅ Listo para activar Pages

================================================================

PASO 2: Abre esto en navegador:

https://github.com/TU_USERNAME/catalina-15

Reemplaza TU_USERNAME.

================================================================

PASO 3: En GitHub, sigue esto:

1. ⚙️ Settings (arriba a la derecha)
2. 📄 Pages (men izquierda)
3. Selecciona: 
   - Branch: main
   - Folder: / (root)
4. ✅ Save

Espera 1-2 minutos. ¡Listo!

================================================================

PASO 4: Tu link estará en:

https://TU_USERNAME.github.io/catalina-15/

Cópialo y ¡comparte! 🎉

================================================================

🆘 SI ALGO NO FUNCIONA:

• ¿Error "remote already exists"? Borra la carpeta .git y empieza de nuevo
• ¿No aparece el link? Espera 2-3 minutos y recarga
• ¿404? Verifica que sea "public" el repo en GitHub

Más detalles: GITHUB_PASO_A_PASO.md
